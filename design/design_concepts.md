# JavaScript Gallery Design Concepts

Since we're building a gallery for `.js` files, we have a unique opportunity to make the code itself the "hero" of the design. Here are three creative directions that move away from standard photography portfolios and lean into the nature of JavaScript.

---

## Concept 1: The "Neuro-Code" Graph
**Visual Style**: Dark, futuristic, immersive.
**Experience**:
- **Interactive Map**: Instead of a grid, files are nodes in a floating, physics-based connection graph.
- **Dynamic Relationships**: Lines connect files based on shared tags, complexity, or date.
- **Glassmorphism**: Code snippets appear in frosted glass panels that follow the cursor or "pop" from the nodes.

## Concept 2: The "Infinite Canvas" (Architectural)
**Visual Style**: Blueprint aesthetic, clean, technical, blueprint-blue or schematic-gray.
**Experience**:
- **Pan and Zoom**: A massive, zoomable canvas where files are laid out like architectural drawings.
- **Macro/Micro View**: Zoom out to see the "city" of your projects; zoom in to see individual lines of code with detailed technical annotations.
- **Technical Overlays**: Subtle grid lines, coordinates, and "schematic" UI elements (like rulers or scale markers).

---

## Concept 3: The "Cinematic Sequence" (Vertical/Horizontal Scroll)
**Visual Style**: High-contrast, minimalist, focus on typography and motion.
**Experience**:
- **Storytelling**: Each file is a "chapter". As you scroll, the code "assembles" itself on the screen with elegant animations.
- **Full-Bleed Visuals**: Each script has a background generated by its own logic (e.g., a canvas animation driven by a snippet from that specific file).
- **Depth of Field**: Using CSS filters to create a sense of focus on the active piece of code, blurring the rest.

---

## Core Aesthetics (Common to all)
- **Modern Typography**: Using **Outfit** or **Inter** for UI, and **JetBrains Mono** or **Fira Code** for the snippets.
- **Vibrant Palettes**: Deep charcoal backgrounds with electric blue (`#00D2FF`), magenta (`#FF00E5`), and emerald (`#00FFA3`) accents.
- **Micro-animations**: Hover states that feel "magnetic," smooth scroll transitions, and glowing code syntax.
